# Pépites 💎

Des fun facts en français, une carte à la fois. Glisse vers le haut : une pépite. Encore : une autre.

- Plus de 11 000 pépites tirées du « Le saviez-vous ? » de Wikipédia, en 14 matières
- Quiz « Te souviens-tu ? », objectif du jour, série de jours avec jokers, pépites en or, défi de la semaine
- Le bouton « pourquoi ? » explique chaque pépite ; partage en image ; lecture à voix haute
- 4 papiers dessinés à la main, marche hors ligne

## Télécharger

➡️ **[Dernière version (APK Android)](https://github.com/serpentd1/pepites/releases/latest)**

Sur le téléphone : ouvre le fichier `pepites-x.y.z.apk`, autorise « l’installation d’applications inconnues » pour l’appli qui l’ouvre (Chrome, Fichiers…), puis lance Pépites. Android 7.0 ou plus récent.

## Ce dépôt

Il sert de point de distribution, pas de code source :

| Fichier | Rôle |
| --- | --- |
| `distribution/version.json` | dernière version ; l’appli propose de la télécharger quand il y en a une plus récente |
| `distribution/facts-extra.json` | nouvelles pépites, ajoutées toutes seules dans l’appli (une fois par jour au plus) |
| `confidentialite.html` | [politique de confidentialité](https://serpentd1.github.io/pepites/confidentialite.html) |
